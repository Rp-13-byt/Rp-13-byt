IMPORTANT: GitHub's website can be awkward with dot-folders such as .github.
If you cannot upload the folder, don't try to upload the folder itself. Use one of these methods:

METHOD A — GitHub website (no terminal)
1. Open https://github.com/Rp-13-byt/Rp-13-byt
2. Edit README.md, replace its contents with the README.md from this package, and commit.
3. In the repository, choose Add file > Create new file.
4. In the filename field, enter exactly: .github/workflows/snake.yml
5. Open the root-level snake.yml file from this package in Notepad, copy all its contents into GitHub, then commit. This creates the required nested path.
6. If a misplaced snake.yml exists at the repository root, delete that old root-level file. Keep only .github/workflows/snake.yml.
7. Open the Actions tab and run “Generate Contribution Snake”.

METHOD B — GitHub Desktop or local Git
1. Extract this ZIP.
2. Copy README.md and the .github folder into your local clone of Rp-13-byt/Rp-13-byt.
3. Commit and push the changes.
4. Delete any old root-level snake.yml if present.
5. Run “Generate Contribution Snake” under the repository's Actions tab if needed.

The snake image will not appear until the workflow succeeds and publishes the SVG to the output branch.
